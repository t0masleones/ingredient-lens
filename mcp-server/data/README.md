# Ingredient data

The rules engine builds `ingredients.db` (SQLite, not versioned) from two CSV files. When both have the same term, the curated row wins.

| File | Rows | Source | License | Trust |
|---|---|---|---|---|
| `ingredients.csv` | 430 | Curated from `agent/knowledge/` glossaries, each row with its source; rows marked `v0.2-added` / `v0.2.1-added` have no cited source yet | Same as the repo | Highest: decides lactose, gluten and allergens |
| `off-terms.csv` | 10,902 | Generated by `import_off.py` from the [Open Food Facts](https://world.openfoodfacts.org) additives and ingredients taxonomies (Portuguese, English and Spanish names; E/INS codes) | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), © Open Food Facts contributors | Diet status (vegan / vegetarian) only; allergens are not assumed absent |

## How the Open Food Facts terms are made safe
- **Diet:** `vegan: yes` → origin `non_animal`; `maybe` → `either` (🟡); `no` → `animal`, with the vegetarian status as `slaughter` (🔴 for vegetarians), `maybe_slaughter` (🟡) or `non_slaughter`. Values are inherited from parent ingredients.
- **Allergens:** an animal allergen (milk, egg, fish, crustacean, mollusc) is ruled out only for vegan ingredients. A plant allergen (gluten, soy, peanut, tree nuts, sesame) is ruled out only for fruit, vegetables, herbs, spices, salt and water. Every other group goes to `may_allergens`, so the engine answers 🟡, never 🟢.
- **Known allergens** come from the parent ingredient (a child of milk, wheat, soya...) and from curated terms inside the name ("farinha de trigo integral" inherits gluten from "trigo").
- **Additives:** only the codes that can come from an allergen carry a flag: E322 lecithins (soy or egg), E1105 lysozyme (egg), E966 lactitol (made from lactose), and modified starches E1404-E1452 (may be wheat). Label law (RDC 727/2022 in Brazil, Regulation 1169/2011 in the EU) still requires declaring the allergen source of an additive.
- **Sugar:** Open Food Facts marks sugars "maybe vegan" because of bone-char filtering. The project treats that as an invisible processing aid (see `agent/knowledge/origin-glossary.md`), so sugars are imported as plant-based with that note.
- **Tests:** `tests/test_open_food_facts.py` checks known traps (semolina, malt, bread, kefir, tofu...) and that no imported term drops an animal allergen without being vegan.

## Refresh
```
uv run data/import_off.py            # downloads the current taxonomies
uv run data/import_off.py <folder>   # or uses additives.json and ingredients.json from a folder
uv run pytest && uv run eval_rules.py
```
Review the diff of `off-terms.csv` before committing: Open Food Facts is edited by volunteers.

## Regulated sources considered
| Source | What it gives | Status |
|---|---|---|
| Codex CXG 36-1989 (INS) | International additive numbers and functional classes | Used indirectly: E and INS numbers are usually the same, so codes are imported as both `E322` and `INS 322` |
| Anvisa IN 211/2023 | Additives authorized in Brazil, with INS, function and limits | No machine-readable file found; cited in the label rules |
| EU additives database (Regulation 1333/2008, Annex II) | Authorized E numbers | No bulk download found; Open Food Facts follows this list |
| FDA Substances Added to Food | ~4,000 substances used in US food | Searchable only; candidate for a later import |
| RDC 727/2022, FALCPA / FASTER Act, Regulation 1169/2011 | Which allergens a label must declare | Encoded in `agent/knowledge/label-rules-br-us-eu.md` |
