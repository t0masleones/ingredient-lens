# Ingredient data

The rules engine builds `ingredients.db` (SQLite, not versioned) from two CSV files. When both have the same term, the curated row wins.

| File | Rows | Source | License | Trust |
|---|---|---|---|---|
| `ingredients.csv` | 653 | Curated from `agent/knowledge/` glossaries and regulations, each row with its source. 64 rows added without a source were later confirmed against Open Food Facts; 15 still need one (see `tests/evidence/curated-crosscheck.md`) | Same as the repo | Highest: decides lactose, gluten and allergens |
| `off-terms.csv` | 35,043 | Generated by `import_off.py` from the [Open Food Facts](https://world.openfoodfacts.org) additive and ingredient taxonomies: names and synonyms in Portuguese, English, Spanish, French, German, Italian and Dutch; E/INS codes | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), © Open Food Facts contributors | Diet status (vegan / vegetarian) and known allergens; a missing allergen fact is never read as "absent" |

Terms per language in `off-terms.csv`: Portuguese 2,130 · English 7,258 · Spanish 3,663 · French 6,919 · German 5,162 · Italian 4,595 · Dutch 3,176 · additive codes 2,140.

## How the Open Food Facts terms are made safe
- **Diet:** `vegan: yes` → origin `non_animal`; `maybe` → `either` (🟡); `no` → `animal`, with the vegetarian status as `slaughter` (🔴 for vegetarians), `maybe_slaughter` (🟡) or `non_slaughter`. Values are inherited from parent ingredients.
- **Allergens ruled out only with evidence:** milk, egg, fish, crustacean and mollusc only for vegan ingredients; gluten, soy, peanut, tree nuts and sesame only for fruit, vegetables, herbs, spices, salt and water; celery, mustard, sulphites and lupin never (dried fruit can hold sulphites, spice mixes mustard or celery). Every other group goes to `may_allergens`, so the engine answers 🟡, never 🟢.
- **Known allergens** come from the `allergens` property in the taxonomy, the parent ingredient (a child of milk, wheat, soya...) and curated terms inside the name ("farinha de trigo integral" inherits gluten from "trigo"). A vegan ingredient never inherits milk, egg or fish from a word in its name ("nata de coco").
- **Taxonomy quirks corrected:** peanuts sit under "nuts" in Open Food Facts but are not tree nuts; "shellfish" mixes crustaceans and molluscs, so it is not used.
- **Languages:** a French, German, Italian or Dutch term never replaces a Portuguese, English or Spanish one ("polvo" is octopus in Portuguese, powder in Spanish), and short or common words are skipped.
- **Additives:** only the codes that can come from an allergen carry a flag: E322 lecithins (soy or egg), E1105 lysozyme (egg), E966 lactitol (lactose), modified starches E1404-E1452 (may be wheat) and sulphites E220-E228 (EU allergen).
- **Sugar:** Open Food Facts marks sugars "maybe vegan" because of bone-char filtering. The project treats that as an invisible processing aid (see `agent/knowledge/origin-glossary.md`), so sugars are imported as plant-based with that note.
- **Tests:** `tests/test_open_food_facts.py` checks known traps, EU-language terms and the "never ruled out without evidence" invariant on every imported row.

## Refresh
```
uv run data/import_off.py              # downloads the current taxonomies (JSON and source .txt with synonyms)
uv run data/import_off.py <folder>     # or reads them from a folder
uv run data/crosscheck_curated.py <folder> [--apply]   # re-check curated rows without a source
uv run pytest && uv run eval_rules.py
```
Review the diff of `off-terms.csv` before committing: Open Food Facts is edited by volunteers.

## Regulated sources considered
| Source | What it gives | Status |
|---|---|---|
| Codex CXG 36-1989 (INS) | International additive numbers and functional classes | Used through the E/INS code mapping |
| Anvisa IN 211/2023 | Additives authorized in Brazil, with INS, function and limits | No machine-readable file found; cited in the label rules |
| EU additives database (Regulation 1333/2008, Annex II) | Authorized E numbers | No bulk download found; Open Food Facts follows this list |
| FDA Substances Added to Food | ~4,000 substances used in US food | Searchable only; candidate for a later import |
| RDC 26/2015 (in RDC 727/2022), FALCPA / FASTER Act, Regulation 1169/2011 | Which allergens a label must declare | Encoded in the engine (`MARKET_ALLERGENS`) and in `agent/knowledge/label-rules-br-us-eu.md`; cited by the EU allergen rows (`eu-1169-2011-annex-ii`) |
